# Kuluseuranta

Yksinkertainen komentorivipohjainen kuluseurantasovellus Pythonilla.

## Mitä ohjelma tekee?
Ohjelman avulla käyttäjä voi kirjata ylös ostoksia ja tarkastella kulutustilastoja:
- **Lisää kulu:** Tallentaa ostoksen nimen ja hinnan.
- **Näytä kulut:** Listaa kaikki syötetyt kulut.
- **Näytä tilasto:** Laskee ja tulostaa kokonaiskulut sekä pienimmän ja suurimman yksittäisen kulun.

## Käyttöohje
1. Varmista, että tietokoneelle on asennettu Python 3.
2. Aja ohjelma terminaalissa komennolla:
   ```bash
   python kuluseuranta.py
   ```
3. Valitse haluamasi toiminto valikosta syöttämällä numero 1–4.
