# Tuoterekisteri

Yksinkertainen komentorivipohjainen tuotehallinta- ja varastosovellus Pythonilla.

## Mitä ohjelma tekee?
Ohjelman avulla käyttäjä voi hallita varaston tuotteita valikon kautta:
- **Listaa tuotteet:** Näyttää kaikki varastossa olevat tuotteet, niiden kappalehinnat ja kappalemäärät.
- **Lisää tuote:** Lisää uuden tuotteen varastoon.
- **Poista tuote:** Poistaa tuotteen varastosta nimen perusteella.
- **Näytä varaston kokonaisarvo:** Laskee kaikkien tuotteiden yhteenlasketun arvon.

## Käyttöohje
1. Varmista, että tietokoneelle on asennettu Python 3.
2. Aja ohjelma terminaalissa komennolla:
   ```bash
   python tuoterekisteri.py
   ```
3. Valitse haluamasi toiminto valikosta syöttämällä numero 0–4.
